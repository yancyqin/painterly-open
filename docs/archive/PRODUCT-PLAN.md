# 产品与验证计划

> **已归档 2026-07-20** — 原始产品/验证计划。MVP 已建成;收费模型已定稿(前三层免费 + $1.99 一次解锁,见 ../MONETIZATION-BUILD.md);验证指标部分未再跟踪。仅作历史参考。

## 1. 产品判断

值得继续验证，但应验证的不是“低价双人在线游戏”，而是：

> 一个人制作一个漂亮、有趣的艺术伪装谜题，发到短信、家庭群、课堂或 Discord，让许多人在 24 小时内来找。

这个变化解决了原方案最大的结构性问题：不再要求两个人同时在线。它也把手机从“需要兼容的平台”变成主要传播工具，因为创建者分享一个链接，接收者点击就能玩。

当前最有希望的付费逻辑是“创作者付费，参与者免费”：

- 免费用户可以在第一个艺术房间创建和游玩挑战。
- Hider 购买一个高级艺术房间后，可以在该房间创建挑战。
- 收到邀请的所有 Seekers 都免费进入该挑战，不需要账户或购买。
- 付费购买的是永久房间使用权，而不是一次挑战、生命、时间或更高胜率。

这比统一收取 $0.99 更符合分享型游戏：每一位付款者都可以带来多位无摩擦玩家。

## 2. 核心循环

### Hider

1. 选择艺术房间。
2. 选择变色龙或可伪装物体的位置、姿态和比例。
3. 用少量创意画笔绘制伪装。
4. 预览 Seeker 视角。
5. 发布挑战，获得不可猜测的分享链接。
6. 把链接发给一个群体。
7. 在 24 小时内查看汇总结果：参与人数、找到比例、时间分布。

Hider 的创作阶段没有时间限制。未发布草稿优先保存在本地，不占服务器空间。

### Seeker

1. 打开链接，不注册。
2. 加载房间和挑战。
3. 点击“开始寻找”后才启动计时。
4. 移动 Seeker，把前方 inspection 圆圈对准目标，再按 R、Space 或点击/轻触检查。
5. 看到成绩和轻量反馈，然后可创建自己的免费挑战。

一个挑战允许多个 Seeker 独立尝试。MVP 不显示实时在线人数，也不需要他们彼此可见。

## 3. MVP 范围

### 必须有

- 手机、平板和桌面响应式布局。
- 一个免费、来源已核验的艺术房间。
- Hider 编辑器、预览和发布。
- 高熵分享链接。
- 一个 Hider 对多个 Seeker。
- Seeker 明确开始后计时。
- 24 小时硬过期。
- 基本结果页和匿名汇总。
- 删除/举报入口。
- 英文优先，但文案结构必须可本地化。

### 可以稍后有

- 第二、第三个付费艺术房间。
- Discord Activity。
- 无账号购买恢复或跨设备账户。
- 成就解锁画笔。
- 课堂模式和教师控制台。
- 同一挑战的异步排行榜。
- 公开挑战页：难题、新题和随机题三个小型内容带；当前 24 小时验证默认公开、可取消，未来长期内容和高级房间再要求账户。

### 明确不做

- Code Brush。
- 无账户、无审核、允许自由文本的开放式作品广场。
- 聊天、语音、好友系统和自由文本标题。
- 广告和行为广告 SDK。
- 金币、宝石、能量或随机奖品。
- 默认实时对战、匹配队列和 WebSocket 房间。
- “毕加索房间”等尚未完成权利审查的商业内容。

## 4. 收费实验

首轮验证期间不急于收费。先确认免费房间是否自然产生分享和回流，再测试：

- 单个高级艺术房间永久解锁。
- 三个房间组成的 Museum Pass。
- 家庭包或课堂包只在出现真实需求后考虑。

暂不锁定价格。建议测试区间而不是先写死商业模型：单房间可从 $1.99–$3.99 开始，组合包从 $4.99–$7.99 开始。实际价格还要考虑平台最低价、分成、税务、退款和地区定价。

不建议在 MVP 中把画笔做成代币内购。代币会引入余额、退款、儿童购买、跨平台同步和商店政策问题，却不能证明核心分享循环成立。创意画笔先作为房间自带内容或成就解锁内容。

## 5. 最重要的验证指标

### 核心漏斗

- `publish_rate`：开始创作的人中，成功发布挑战的比例。
- `share_intent_rate`：发布后点击系统分享或复制链接的比例。
- `invite_open_to_begin`：打开邀请后真正点击开始的比例。
- `seek_completion_rate`：开始后找到目标或主动结束的比例。
- `seekers_per_published_challenge`：每个挑战的独立 Seeker 中位数。
- `seeker_to_hider_conversion`：完成寻找后创建自己挑战的比例。
- `day_7_creator_return`：七天内再次创建挑战的 Hider 比例。

### 付费前置门槛

只有下面三件事同时出现，付费房间才值得实现：

1. 每个已发布挑战能稳定带来多于一个 Seeker，而不是大量零打开链接。
2. 一部分 Seeker 会转为新的 Hider，形成循环。
3. 用户主动要求更多房间、美术或创作变化，而不只是要求更多免费流量。

### 否决信号

- 大多数 Hider 完成创作却不愿分享。
- 分享链接被打开，但手机端大量用户不开始或无法顺利完成。
- 多人尝试没有提高创建者复玩意愿。
- 高级房间的吸引力依赖具体艺术家名字，而不是玩法和视觉质量。

出现这些信号时，应先改产品循环，不应靠同时发布更多平台来掩盖问题。

## 6. 四个一周里程碑

### 第 1 周：拆分与手机闭环

- 完成代码和资产盘点。
- 提取平台无关的游戏核心。
- 做出一个房间的手机端创建、分享和寻找闭环。
- 建立资产来源台账。

### 第 2 周：异步服务

- Worker API 与独立 D1。
- 24 小时过期读取和 Cron 清理。
- 多 Seeker 尝试和匿名汇总。
- 链接滥用、速率限制、删除和举报。

### 第 3 周：小范围真实分享

- 只邀请家庭、朋友和少量课堂测试者。
- 观察加载、开始、完成、分享和再次创建。
- 不用口头好评代替行为数据。

### 第 4 周：商业门槛复盘

- 判断是否达到付费前置门槛。
- 达到：实现一个支付适配器和一个高级房间。
- 未达到：先修分享或手机体验，不同时扩张四个平台。
